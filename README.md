# 人生推演仪

> 25 岁的存款 5 万，30 岁会走到哪里？
> 三个大模型，替你把这条路先走一遍。

教练规划方向，你落笔行动，现实世界给出反馈——机遇、挫折、意外，还有不停流逝的时间。每一轮是一个季度，二十轮走完五年：你会在第几轮跳槽？创业在第几轮失败？拖延症在第几轮拖垮计划？

**多智能体推理你的人生，推演一遍再出发。**

## 三个声音，一场人生

| 角色        | 扮演者 | 在做什么                               | 现实中的对应 |
| --------- | --- | ---------------------------------- | ------ |
| **B 教练**  | 大模型 | 纵观全局、制定规划、给出下一步、撰写总结               | 人生导师   |
| **A 执行者** | 大模型 | 以你的名义行动——带着你的性格：拖延的人会反复搁置，自律的人高效推进 | 你自己    |
| **C 环境**  | 大模型 | 模拟现实反馈：外貌出众者易获善意，孤僻固执者容易碰壁，机遇与意外并存 | 命运     |

每一轮循环：**教练规划 → 执行者行动 → 环境反馈 → 记录归档 → 教练总结**。年龄按累计周数精确折算，资源随推演增减，目标完成度逐轮累积——像真实人生一样，没有回滚键。

## 它特别在哪

- **完全在浏览器里运行**——没有后端，没有服务器，你的 API Key 只在浏览器内存中直连模型服务商，**不被记录、不被公开**
- **推演可分享**——任意一次推演可编码成一条链接发给朋友，对方打开即看完整人生历程，无需注册、无需存储
- **时间真实流逝**——支持「节奏快 · 约3年」与「按季度 · 约5年」两档时间尺度，每轮行动有预计耗时，现实中可能提前也可能延期
- **性格影响命运**——填入「拖延、社恐」或「自律、外向、漂亮」，执行难度与现实反应都会随之改变
- **断点续推**——推演到一半关掉页面，回来接着走
- **模型自由**——三个角色可分别选择不同模型，也可填任意自定义模型 ID；OpenRouter 免费池与魔搭 Flash 模型开箱即用

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 <http://localhost:5173>，填入 API Key 即可开始推演。

**没有 Key？** 去 [openrouter.ai/keys](https://openrouter.ai/keys) 免费注册一个（免费模型），或使用[魔搭访问令牌](https://modelscope.cn/my/myaccesstoken)。

### 可选：本地 key 预填

在项目根目录创建 `.env.local`（已被 `.gitignore` 忽略，不会提交）：

```
VITE_OPENROUTER_KEY=你的key
VITE_MODELSCOPE_KEY=你的key
```

> **警告**：Vite 的 `VITE_*` 变量会打包进前端产物。**公开部署前请清空/删除** **`.env.local`** **再构建**，否则 key 会随构建产物泄露给所有访问者。

<br />

## 隐私承诺

- **API Key 只存在于访问者自己的浏览器内存中**，仅在推演时直连模型服务商，不经过任何中间服务器，不写入任何数据库
- **本地历史存档**保存在浏览器 `localStorage`，只包含推演内容，不含 key
- **分享链接**只编码推演内容（人生设定、各轮规划与结果、总结报告），**永远不包含 API Key**
- 因此：在网上访问本站、填上自己的 key 进行推演，**key 不会被记录、不会被公开**

## 技术栈

React 18 + TypeScript + Vite + Tailwind CSS + Zustand + React Router（hash 模式）

```
src/
├── lib/
│   ├── prompts.ts      # 三个智能体的系统提示词（时间尺度动态注入）
│   ├── llm.ts          # OpenAI 兼容 API 浏览器直连客户端（重试/退避）
│   ├── engine.ts       # 推演引擎：规划→行动→反馈→记录 循环
│   ├── share.ts        # 分享码编码/解码（gzip + base64url）
│   ├── history.ts      # localStorage 历史存档
│   └── models.ts       # 服务商与模型清单
├── store/simStore.ts   # 推演状态机
└── pages/              # Setup / Simulate / Journey / History / Gallery
```
